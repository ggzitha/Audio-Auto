Help

Step-by-step guide to configuring and adding ESP32 clients.

1 Preparing the Hardware

The system supports standard ESP32 (using internal DAC) and ESP32-C3/C6 (using an external PCM5102 I2S module).

  • For ESP32: Connect external speakers to GPIO25 or GPIO26 (Internal DAC) and GND. Note that audio quality will be lower (8-bit).
  • For ESP32-C3 / C6: Connect a PCM5102 module via I2S. Connect BCLK, LRC, and DIN to the assigned pins in the Arduino Sketch. Connect the Aux Out from PCM5102 to your speakers.

2 Configuring the Arduino Sketch

Open the Audio_Client.ino file in the Arduino IDE. You need to configure a few specific variables for each device before flashing.

// Set a unique name for each ESP32. This name will appear in the Dashboard.
const char* DEVICE_NAME = "ESP32-Ruang-A001";

The code already contains the 3 WiFi SSIDs and the MQTT credentials. The ESP32 will automatically connect to the strongest available WiFi network.

3 Auto-Registration

Once flashed, power on the ESP32. It will:

  1. Connect to WiFi.
  2. Sync time with NTP (pool.ntp.org) to UTC+9.
  3. Connect to the MQTT Broker (192.168.88.8).
  4. Start publishing telemetry data (Status, IP, RSSI, Temp).
As soon as the web application receives the first MQTT telemetry message, the device will be automatically registered and appear on the Devices page.

4 Scheduling Audio

To schedule audio playback:

  1. Upload an audio file (.mp3, .wav, .flac) via the Dashboard.
  2. Go to the Scheduler page.
  3. Click Add Schedule.
  4. Select the target Device (or All Devices), the Audio File, and set the precise Date & Time and Volume.
  5. The server will automatically trigger playback exactly at the scheduled time with zero delay synchronization across all devices.
